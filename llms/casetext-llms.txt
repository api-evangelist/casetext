# Casetext

> RETIRED BRAND — NOT A LIVE API PROVIDER. Casetext was a legal-technology company founded in
> 2013 (Jake Heller, Joanna Huey, Laurence Pfeffer, San Francisco) that built an early neural
> search engine for U.S. case law (Parallel Search), the SmartCite citator, the AllSearch
> private-document search tool, the Compose brief-drafting product, and CoCounsel — a
> generative-AI legal assistant released in March 2023 on OpenAI's GPT-4. Thomson Reuters
> acquired Casetext for $650 million in cash, closing 2023-08-17, and retired the standalone
> platform on 2025-04-01. As of 2026-08-10 every path on casetext.com returns HTTP 410 Gone
> and the apex redirects to thomsonreuters.com/en/cocounsel.

This file is GENERATED by API Evangelist from the catalog profile. Casetext never served an

## API surface

There is none, and there never was a public one.

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, or Postman collection was ever published.
- No developer portal, API reference, API keys, or webhooks.
- No client SDKs. The 15 npm packages Casetext published under github.com/casetext are
  general-purpose JavaScript utilities (Firebase wrappers, a Quill delta renderer, an FNV
  hash, a PEG.js importer, a local Lambda runner, a cron scheduler), not API clients. The
  most recent release is `ultracron@0.0.7`, published 2018-06-08. Every backing repository
  is archived.
- api.casetext.com, developer.casetext.com, docs.casetext.com, app.casetext.com and
  cocounsel.casetext.com do not resolve (NXDOMAIN).
- Every `/.well-known/` path returns 410, including agent-card.json and agent.json.

If you are looking for a machine-readable legal-research contract, this is a dead end. Look
at the Thomson Reuters profile instead — the capability moved there.
